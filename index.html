03 / Solo project

Orquestador de IA Local
Híbrido Cloud + GPU

Sistema que orquesta un modelo local (Qwen 35B MoE en RTX 3070 Ti) con Claude en la nube para ejecutar planes de codificación multi-paso de forma autónoma. El executor monitoriza cambios por MD5, detecta desbordamientos de contexto y lanza un supervisor que genera sub-planes de recuperación automáticos sin intervención manual.

Python llama.cpp CUDA Aider Claude API JSON Schema Q4_K_M quantization
18 t/s Inferencia local — RTX 3070 Ti
256K Tokens de contexto en 8 GB VRAM
35B Parámetros (3B activos por token, MoE)
−73% Reducción de tamaño vía Q4_K_M
